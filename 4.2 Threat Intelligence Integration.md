Operationalise threat intelligence feeds into SOC workflows.

# 📋 Procedure

## 🌐 Step 1: Ingest OSINT Threat Feeds

> **Purpose:** Integrate Open-Source Intelligence (OSINT) feeds into the Security Operations Center (SOC) to improve detection and investigation capabilities.

### Splunk Integration

* Install the **TA-Threat-Intel** application.
* Configure the **AlienVault OTX API Key**.

---

### MISP Integration

Install **MISP (Malware Information Sharing Platform)** and import threat intelligence feeds from:

* CIRCL
* abuse.ch
* EmergingThreats

### List Available Intelligence Modules

```bash
misp-modules -l
```

---

### Additional Threat Intelligence Sources

* Integrate the **Shodan API** for asset exposure intelligence.
* Subscribe to the following intelligence sources:

  * CISA Advisories
  * MS-ISAC
  * Sector-specific ISACs

---

## 📥 Step 2: Create IOC Lookup Tables in Splunk

### Download a Malicious IP Address List

```bash
curl https://feodotracker.abuse.ch/downloads/ipblocklist.csv -o iocs.csv
```

---

### Upload IOC Lookup Table

Navigate to:

```text
Settings → Lookups → Lookup Table Files
```

Upload:

```text
iocs.csv
```

---

### Create a Lookup Definition

Create the lookup definition:

```text
bad_ips.csv
```

Configure the following fields:

* `ip`
* `threat_category`
* `confidence`

---

### Example Splunk Search

```spl
index=network_logs
| lookup bad_ips src_ip as ip OUTPUT threat_category
| where isnotnull(threat_category)
```

---

### Configure Automatic Refresh

Set the lookup table to refresh automatically:

* Every **24 hours**

---

## 🛡️ Step 3: MITRE ATT&CK Mapping

### Use ATT&CK Navigator

Access:

```text
https://mitre-attack.github.io/attack-navigator/
```

### Tasks

* Map every current detection to the appropriate **MITRE ATT&CK Tactic and Technique**.
* Identify coverage gaps.
* Prioritise new detection rules for uncovered techniques.
* Tag all incidents with ATT&CK TTP codes for trend analysis.
* Share the ATT&CK coverage map with management on a monthly basis.

# ✅ Best Practice Tips

### 📌 Enrich Every Alert

Automatically enrich every alert with threat intelligence **before analyst review**.

> This can reduce triage time by approximately **40–60%**.

---

### 📌 Prioritise High-Confidence IOCs

Focus on:

* High-confidence Indicators of Compromise (IOCs)
* Low false-positive indicators

> Quality is more valuable than quantity in threat intelligence.

---

### 📌 Establish an IOC Lifecycle

Implement an IOC lifecycle that includes:

```text
Ingest → Validate → Alert → Expire
```

> IOCs older than **90 days** generally lose operational relevance.

---

### 📌 Participate in Threat Intelligence Communities

Join industry-relevant intelligence-sharing communities, such as:

* ISACs
* FS-ISAC
* H-ISAC

---

### 📌 Validate Threat Intelligence

Always validate threat intelligence against your own environment before generating alerts.

> ⚠️ A globally malicious IP address may legitimately belong to your organization's CDN or trusted infrastructure.
